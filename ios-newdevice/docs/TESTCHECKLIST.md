# NewDevice 自测清单

在 Dopamine rootless 设备上安装 deb 并 Respring 后执行。

## 基础

- [ ] 桌面出现 NewDevice App，可正常打开
- [ ] `curl http://127.0.0.1:8080/` 返回 OK（daemon 存活）
- [ ] 首次打开后存在记录「原始机器」

## 一键新机

- [ ] 应用页勾选 1 个测试 App 并保存
- [ ] 首页点「一键新机」，当前记录名变为时间戳格式
- [ ] 参数摘要中 IDFA/Serial/机型等非空且与原始不同
- [ ] 再次新机生成另一条记录，可在记录页看到多条
- [ ] 「原始机器」可切回，目标 App 数据被清理或按策略处理

## Tweak 生效

- [ ] 将 NewDevice 自己或测试 App 勾选为目标
- [ ] 打开探测页（或测试 App），IDFA/系统版本/hw.machine 与当前记录一致
- [ ] 切回「原始机器」后探测值恢复真实机（需杀进程重开）

## 定位 / 飞行 / IP

- [ ] 开启伪装定位后，测试 App 读到的坐标接近记录中的经纬度
- [ ] 开启智能飞行后，一键新机过程中飞行模式有开关动作（若私有 API 不可用则仅提示）
- [ ] 首页 IP：变化为正常色，未变化为红色

## 防越狱

- [ ] 基础模式：目标 App 内检测常见路径应失败（用自建探针或已知检测）
- [ ] 深度模式默认关闭；打开后若目标 App 闪退，关闭深度模式可恢复

## 全息备份

- [ ] 在记录 A 下往目标 App 写入可观察数据
- [ ] 一键新机到记录 B（数据应被换走/清空）
- [ ] 切回记录 A，数据恢复

## 脚本 API

- [ ] 打开 NewDevice App，首页显示 API 已监听
- [ ] 手机上访问 `http://127.0.0.1:8080/` → `NewDevice API OK`（电脑浏览器会打不开，属正常）
- [ ] `http://127.0.0.1:8080/cmd?fun=newRecord` → 立刻 200 `accepted`，结果文件最终为 `1`
- [ ] `getCurrentRecordName` / `nextRecord` / `deleteRecord` 行为正常
- [ ] 触动脚本 `scripts/AMG_compat.lua` 中 `AMG.New()` 返回 true
