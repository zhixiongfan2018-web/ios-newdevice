# iOS 一键新机

本仓库实现类 AMG 的越狱端「一键新机」套件，源码位于 [`ios-newdevice/`](ios-newdevice/)。

**Sileo 固定源（只用这一条，可直接添加）：**

```
https://zhixiongfan2018-web.github.io/ios-newdevice
```

请删掉其它旧源。添加后刷新 → 安装 → Respring。

> `https://zhixiongfan.top/stable` 需先在服务器按 [`deploy/nginx-zhixiongfan.top-stable.conf`](deploy/nginx-zhixiongfan.top-stable.conf) 配好反代，否则会 302 到 Dial，Sileo 提示超时、无法添加。

完整说明：[`ios-newdevice/README.md`](ios-newdevice/README.md)。
